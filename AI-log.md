ChatGPT (GPT-5.6 Sol) was used throughout the project as a support tool for both technical discussion and report development. AI was used to help discuss and evaluate the network architecture, including VLAN and subnet planning, pfSense routing and firewall configuration, Open vSwitch, trunking, resident-to-resident isolation, PacketFence NAC, Keycloak SSO, network monitoring and quarantine concepts. It was also used during troubleshooting of the Google Cloud and EVE-NG environment, including connectivity, NAT, virtual machine configuration and general Linux networking commands.

AI was also used to review the project requirements and marking rubric, separate the MVP requirements from stretch goals, assist with planning the remaining implementation order, and provide feedback on the network design and project documentation. For the progress report, ChatGPT was used to help structure sections, evaluate existing writing against the rubric, improve clarity, develop the project progress tables, and assist with reflection and action-plan ideas.

The AI was primarily used for guidance, evaluation, troubleshooting support and written feedback rather than completing the practical implementation. Network configuration, deployment, testing, screenshots, evidence and final technical decisions were completed and verified by myself and relevant team members. AI-generated information was reviewed and adjusted before being included within the project or assessment documentation.

# AI Use

| Week       | Example Prompt to ChatGPT                                                                                                                        | Summary of ChatGPT Response / How it was Used                                                                                                                                                                                                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Week 1** | “Can you help me break down the ED-1 Residential College Network scenario and identify the main network and security requirements?”              | ChatGPT helped identify the main requirements from the project brief, including high-density networking, BYOD support, resident isolation, NAC/onboarding, guest access, monitoring and abuse handling. This was used to help understand the project scope and begin planning the network design.                                                        |
| **Week 2** | “How should I structure the VLANs and subnets for a residential college network with hundreds of students?”                                      | ChatGPT discussed different approaches to VLAN segmentation and subnet sizing. This assisted with developing the final `10.50.0.0/16` address space and separate VLANs for residents, guests, staff, IoT, management, NAC/SSO, monitoring and quarantine.                                                                                                |
| **Week 3** | “We are building the network in EVE-NG on Google Cloud. What devices/software could we use that are free and work inside a virtual environment?” | ChatGPT discussed virtualised options such as pfSense for routing/firewalling, Ubuntu Server with Open vSwitch for Layer 2 switching, PacketFence for NAC and other open-source services. These suggestions were evaluated before selecting technologies for the network design.                                                                         |
| **Week 4** | “How can I connect pfSense to an Open vSwitch and have multiple VLANs go through one connection?”                                                | ChatGPT explained 802.1Q trunking, access ports and how VLAN-tagged traffic can travel between pfSense and the Open vSwitch. This helped improve my understanding of VLAN trunking and develop the planned core network connection.                                                                                                                      |
| **Week 5** | “How can two residents be on the same VLAN but still be blocked from communicating with each other?”                                             | ChatGPT explained that pfSense firewall rules would not normally stop communication between devices on the same VLAN because the traffic can remain at Layer 2. Open vSwitch port/client isolation was discussed as a possible solution, which influenced the resident-to-resident isolation design.                                                     |
